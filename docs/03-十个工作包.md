# 03 · 十个工作包

十个助理，一人一个包。**包的边界就是 crate 的边界**，接口先冻结再实现，
不允许两个人改同一个文件——这是并行不写出垃圾的唯一办法。

## 分工总表

| # | 代号 | 负责 | crate | 起跑条件 |
|---|---|---|---|---|
| 1 | `kmem` | 物理内存：位图帧分配、连续分配、保留区 | `crates/kmem` | ✅ M1 已交付 |
| 2 | `kvm` + `kpt` | 虚拟内存：纯模型（随机对拍）+ 真实 PTE 操作 + 每进程地址空间 | `crates/kvm`、`crates/kpt`、`mm/paging` | ✅ M1 交付，M6 起每进程一表 |
| 3 | `kheap` + `kslab` | 内核堆：大块边界标记合并 + 小对象 size-class、双释放检测、全量审计 | `crates/kheap`、`crates/kslab` | ✅ M1/M2 已交付 |
| 4 | `ksched` | 调度：runqueue、vruntime、负载均衡模型（M3 起内核真的在用它） | `crates/ksched` | ✅ 已在用 |
| 5 | `kipc` | 进程间通信：管道 + 等待队列已交付；消息队列 / 共享内存 / 信号待后续 | `lumikernel/src/pipe.rs`、`src/fd.rs` | ✅ M7 已交付管道 |
| 6 | `kfs` + `lumifs` | 文件系统：只读 ext2（M5）+ 可写 LumiFS 带 redo 日志（M8）；VFS 抽象与目录待后续 | `crates/kfs`、`crates/lumifs`、`src/fs`、`src/fs2` | ✅ M8 可写且掉电可恢复 |
| 7 | `kuser` | 用户态：ring3 入口、syscall 表（含 open/read/close）、用户指针校验、ELF64 装载、多进程隔离 | `lumikernel/src/{task,syscall,exec}.rs`、`crates/kelf` | ✅ M6 多进程各自地址空间 |
| 8 | `kint` + `kfault` | 中断：IDT/异常表、8259A→LAPIC+IOAPIC、PIT→APIC 定时器、IPI、RTC 基准；向量语义解码单独成 crate | `lumikernel/src/intr`、`crates/kfault` | ✅ M2/M4 已交付 |
| 9 | `kdev` | 设备：PCIe 枚举、virtio split ring 状态机 | `crates/kdev` | M4 后 |
| 10 | `klinux` | 兼容层：Linux syscall 翻译、musl 程序加载 | `crates/klinux` | M6 后 |

内核二进制与引导链（`lumikernel/`）由我（凝光）负责；质量工程（`kqa`：故障注入、fuzz、长跑脚本）也归我。

## 通用规矩（对十个包一律生效）

1. **纯逻辑、可宿主测试**：crate 里不出现 `in`/`out`/`rdmsr`/`cli` 这类指令；
   与硬件打交道的部分通过 trait 注入（`PageProvider`、`BlockDevice`、`Clock`），测试里用 mock。
2. `#![cfg_attr(not(test), no_std)]`，不引入第三方依赖（`[dependencies]` 必须为空）。
3. **不许 panic**：所有可能失败的操作返回 `Result` / `Option`；
   `unwrap()` 只能出现在测试里。`debug_assert!` 可以，`assert!` 不行。
4. **不许隐式分配**：分配必须显式传入并提供，OOM 是正常返回值。
5. 每个 `unsafe` 块上面必须有一行 `// SAFETY:` 说明为什么安全。
6. 测试要求：正常路径 + 边界 + 失败路径 + **随机化模型测试**（对着一个"笨但正确"的参考模型跑 1 万次随机操作）。
7. 公开 API 写中文文档注释；`cargo doc` 不许有 warning。

## 各包接口契约（先冻结，实现按此对齐）

### 1. kmem
```rust
pub const PAGE_SIZE: usize = 4096;
pub struct Frame(pub usize);
pub struct FrameAllocator<'a> { /* bitmap */ }
impl<'a> FrameAllocator<'a> {
    pub fn new(bitmap: &'a mut [u8], total_frames: usize) -> Option<Self>;
    pub fn alloc(&mut self) -> Option<Frame>;
    pub fn alloc_contiguous(&mut self, count: usize) -> Option<Frame>;
    pub fn free(&mut self, f: Frame) -> Result<(), MemError>;   // 双释放必须报错
    pub fn reserve(&mut self, start: Frame, count: usize);
    pub fn stats(&self) -> MemStats;
}
```
验收：与"参考模型"（`Vec<bool>`）对拍 10 万次随机 alloc/free/alloc_contiguous，状态完全一致；
双释放返回 `Err(DoubleFree)` 且不破坏位图。

### 2. kvm
```rust
pub struct PageTableModel { /* 纯数据结构，不含硬件访问 */ }
impl PageTableModel {
    pub fn new() -> Self;
    pub fn map(&mut self, vaddr: u64, paddr: u64, len: usize, flags: Flags) -> Result<(), VmError>;
    pub fn unmap(&mut self, vaddr: u64, len: usize) -> Result<(), VmError>;
    pub fn translate(&self, vaddr: u64) -> Option<(u64, Flags)>;
    pub fn walk(&self, vaddr: u64) -> Walk;   // 返回 4 级索引，供调试器打印
}
```
验收：映射/取消映射后 `translate` 与参考区间表一致；重叠映射、未对齐长度、非规范地址、跨界映射全部返回明确错误码。

### 3. kalloc
```rust
pub trait PageProvider { fn alloc_page(&mut self) -> Option<Frame>; fn free_page(&mut self, f: Frame); }
pub struct SlabAllocator<P: PageProvider> { /* size classes 8..=4096 */ }
impl<P: PageProvider> SlabAllocator<P> {
    pub fn new(provider: P) -> Self;
    pub fn alloc(&mut self, size: usize, align: usize) -> Option<NonNull<u8>>;
    pub fn free(&mut self, ptr: NonNull<u8>, size: usize) -> Result<(), AllocError>;
    pub fn stats(&self) -> AllocStats;
}
```
验收：随机 size 分配释放 20 万次，`stats().in_use == 0` 且页全部归还；
provider 耗尽时返回 `None` 而不是 panic；释放未分配指针返回 `Err`。

### 4. ksched
```rust
pub struct Scheduler { /* 每 CPU runqueue */ }
impl Scheduler {
    pub fn new(cpu_count: usize) -> Self;
    pub fn enqueue(&mut self, tid: Tid, prio: u8, now: u64);
    pub fn pick(&mut self, cpu: usize, now: u64) -> Option<Tid>;
    pub fn dequeue(&mut self, tid: Tid) -> bool;
    pub fn tick(&mut self, cpu: usize, now: u64);
    pub fn load(&self, cpu: usize) -> usize;
}
```
验收：与"理想公平调度"模型对拍 1 万次随机入队/出队/时间推进；
饥饿检测（任何就绪线程等待时间不得超过 `N × 线程数 × 时间片`）；空队列返回 `None`。

### 5. kipc
```rust
pub struct FdTable { /* 每进程 fd → 打开对象 */ }
pub struct Pipe { /* 环形缓冲，读写两端带阻塞标记 */ }
impl Pipe {
    pub fn write(&mut self, buf: &[u8]) -> Result<usize, IpcError>;  // 满 → WouldBlock（或部分写）
    pub fn read(&mut self, out: &mut [u8]) -> Result<usize, IpcError>; // 空 → WouldBlock
    pub fn close(&mut self);
}
```
验收：满/空返回 `WouldBlock` 不阻塞也不丢数据；写满时部分写返回真实字节数；
两端关闭后行为符合 POSIX（读端全关 → 写端 EPIPE）；随机操作对拍参考模型。

### 6. kfs
```rust
pub trait BlockDevice { fn read(&mut self, lba: u64, buf: &mut [u8]) -> Result<(), IoError>; fn block_size(&self) -> usize; }
pub struct Ext2Reader<D: BlockDevice> { /* 只读 */ }
impl<D: BlockDevice> Ext2Reader<D> {
    pub fn mount(dev: D) -> Result<Self, FsError>;
    pub fn lookup(&self, path: &str) -> Result<Inode, FsError>;
    pub fn read_file(&self, inode: Inode, out: &mut [u8]) -> Result<usize, FsError>;
    pub fn list(&self, dir: Inode, out: &mut [DirEntry]) -> Result<usize, FsError>;
}
```
验收：用一个**自己生成**的最小 ext2 镜像（测试代码里构造）读出已知文件内容与目录项；
损坏镜像（魔数错、块号越界、inode 越界）返回错误而不是 panic/越界读。

### 7. kuser
```rust
pub struct ElfImage { pub entry: u64, pub segments: Vec<Segment>, pub phdr: Option<u64> }
pub fn parse_elf64(bytes: &[u8]) -> Result<ElfImage, ElfError>;
pub fn layout_user_stack(stack_top: u64, argv: &[&str], envp: &[&str]) -> Result<u64, ElfError>;
```
验收：解析真实编译产物（测试里内嵌一份 300 字节的最小 ELF）；
截断文件、错误 class、越界 program header、超大 memsz 全部返回明确错误。

### 8. kint
（依赖 arch）中断描述符表抽象、异常号→处理器映射、APIC 寄存器模型、tick 统计。
验收：异常分发用 mock 表验证；tick 统计在 1 万次模拟中断后计数精确。

### 9. kdev
virtio split ring 状态机（纯逻辑：描述符链、avail/used 环、屏障语义）。
验收：与参考实现互发 10 万个 buffer，无丢失、无重复、索引不越界；环满时正确返回 `NotReady`。

### 10. klinux
syscall 号 → 内核操作的分发表 + 参数校验（指针区间、长度上限）。
验收：非法指针、负数长度、未知 syscall 全部返回 `-EFAULT/-ENOSYS` 而不是崩溃。

## 协作纪律

- **接口改动必须先在 `docs/接口变更.md` 记一笔**，并通知所有依赖方；不许悄悄改签名。
- 每个包自带 `tests/`，`cargo test -p <crate>` 必须能独立跑绿。
- 提交粒度：一个包一次提交，提交信息写清"做了什么 + 怎么验证的"。
