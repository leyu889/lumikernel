# 回归用例（S7）

> 规矩：**每个修过的 bug 都要有一条能跑的用例**。修了但没加用例的，按"没修"算——
> 因为下一个人（或者三个月后的我）会以同样的方式再踩一次。

用法：`python scripts/qa.py --s7` 会逐条检查下面"用例"列里的名字是否真的存在于代码里，
不存在的行会被标红（`[缺失]`），所以这张表不会随着代码演进而变成一纸空文。

## 三、怎么加新用例

1. 修 bug 的同时，在**最靠近根因的那一层**加用例：
   - 纯逻辑 → crate 单测（能在宿主机跑，最快）；
   - 涉及硬件/特权 → 内核自检块（`main.rs` 里 `total += 1` 的那一段）；
   - 涉及用户态语义 → `bench` 或 busybox 命令行。
2. 在本文件加一行，写清"现象 / 根因 / 用例名"。**用例名必须是真的**（`qa.py --s7` 会核）。
3. 如果这个 bug 属于"某一类错误"（例如所有 `unsafe` 边界），把教训写进 `docs/04-工程规约.md`，
   而不是只修这一处。
